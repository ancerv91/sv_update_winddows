# sv_update_winddows
Comando actualizacion windows
# Instalacion
```Install-Module PSWindowsUpdate -Force```

# Bloqueo 
```Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass```

# Update 
```Install-WindowsUpdate -AcceptAll -IgnoreReboot```
